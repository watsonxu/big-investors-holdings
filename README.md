# 二级市场大佬持仓看板

跟踪 14 位全球顶级投资人 / 机构 / 政要最新持仓与交易披露的交互式看板。

## 覆盖对象（14）

**13F 季度持仓（12 家）**：巴菲特（伯克希尔）· 段永平（H&H）· 木头姐（ARK）· 李录（喜马拉雅）· 但斌（东方港湾）· 高盛 GSAM · 贝莱德 · 橡树资本 · Baupost · 潘兴广场 · 第三点（Third Point）· **伯里（Scion）**

**非 13F 口径（2 位）**：**佩洛西**（众议院 Periodic Transaction Report，国会交易披露）· **特朗普**（OGE 278e 总统财务披露 + STOCK Act 交易申报）

## 内容

- **总览卡片**：14 家/位的口径、规模或披露口径、标的数、第一重仓
- **持仓明细**：13F 口径显示「占比 / 市值」；非 13F 口径显示「金额区间 / 类别」，不做占比
- **大佬共识**：被多人共同持有/交易的标的（含佩洛西、特朗普、伯里）
- **年化收益率对比**：13F 机构的历史业绩（佩洛西/特朗普为区间口径，不适用）
- **行业配置 & 规模对比**：仅含 13F 多头口径机构
- **最新调仓动态**：2026 年重点变化

## 口径说明（重要）

- **11 家 13F**：2026 Q2（截至 2026-06-30，2026-08-14 截止提交），来自 SEC 原始文件。
- **伯里（Scion）**：基金已关闭，最新 13F 为 **2025 Q3**（2025-11-03 提交），组合以 PLTR/NVDA 看跌期权与 PFE/HAL 看涨期权为主。
- **潘兴广场**：自身仅提交 13F-NT（无明细），完整持仓由上市母公司 **Pershing Square Inc.**（CIK 0002026053）披露，为母公司口径（约 $195 亿）。
- **佩洛西**：非 13F。走**国会交易披露**（Periodic Transaction Report），披露的是**逐笔买卖 + 金额区间**（如 $5M–$25M），并非持仓快照；多为配偶 Paul Pelosi 名下。
- **特朗普**：非 13F。走**总统财务披露**（OGE 278e，年度）+ STOCK Act 交易申报，金额以**区间**列示，交易极频繁（2026 Q1 约 3,700 笔、6 月 1,051 笔）。
- 13F 仅覆盖美股多头持仓，不含做空、多数衍生品与非美资产，存在滞后性。
