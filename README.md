# 二级市场大佬持仓看板

跟踪 11 位全球与中国顶级投资人/机构最新持仓的交互式看板，数据基于 **SEC 13F（2026 Q2，截至 2026-06-30）**。

## 覆盖对象

巴菲特（伯克希尔）· 段永平（H&H）· 木头姐（ARK）· 李录（喜马拉雅）· 但斌（东方港湾）· 高盛 GSAM · 贝莱德 · 橡树资本 · Baupost · 潘兴广场 · 第三点（Third Point）

## 内容

- **总览卡片**：各机构管理市值、持仓数、第一大重仓、Q2 状态
- **完整持仓明细**：按机构切换，代码 / 公司 / 占比 / 市值 / 逐项变动
- **大佬共识**：被多位大佬共同持有的标的对比
- **行业配置 & 规模对比**：行业分布条形图、管理市值环形图、核心标的多机构占比
- **年化收益率对比**：不同时间区间与规模的历史业绩
- **最新调仓动态**：Q2 重点变化（增持 / 减持）

## 口径说明

- 数据来源：SEC 13F 原始文件（8/14 截止提交），部分补充自公开披露。
- **潘兴广场**：其自身仅提交 13F-NT（无明细），完整持仓由上市母公司 **Pershing Square Inc.**（CIK 0002026053）披露，故为母公司口径（约 $195 亿），与 LP 口径不同，直接比较规模时请注意。
- 贝莱德 / 高盛为超大型资管，持仓数以万计，看板仅列前十大。
- 13F 仅覆盖美股多头持仓，不含做空、衍生品（部分）与非美资产，存在滞后性。
